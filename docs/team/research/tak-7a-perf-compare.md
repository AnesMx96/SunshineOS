## 2. The 15 most valuable missing or differing settings, ranked by benefit

Ranked by expected benefit on an ordinary Sunshine desktop/laptop, with implementation status from `docs/team/reports/perf-gaming.patch`:

1. **THP shrinker `max_ptes_none=409`** (`C/usr/lib/tmpfiles.d/thp-shrinker.conf:6`) — cuts THP memory blow-up when THP=always; added with a sysfs-existence guard.
2. **Writeback caps for USB (16 MiB) and HDD (256 MiB)** (`C/usr/lib/udev/rules.d/61-writeback-limits.rules:16-17,25-26`) — prevents multi-minute eject/unmount/suspend stalls; added.
3. **Guarded zram-size increase to `min(ram, 8192)`** (`C/usr/lib/systemd/zram-generator.conf:3`, `G/usr/lib/systemd/zram-generator.conf:2`) — more compressed swap headroom on capable desktops; added with RAM/battery/VM guards.
4. **`fs.file-max=2097152`** (`C/usr/lib/sysctl.d/70-cachyos-settings.conf:44`, already in `S/sunshine-gaming:34`) — avoids descriptor limits in builds and games; added to the profile.
5. **`kernel.sched_cfs_bandwidth_slice_us=3000`** (`G/usr/lib/sysctl.d/20-sched.conf:12`) — SteamOS scheduler granularity for responsiveness; added.
6. **`net.ipv4.tcp_fin_timeout=5`** (`G/usr/lib/sysctl.d/20-net-timeout.conf:15`) — the documented SteamOS fix for games that cannot restart; added.
7. **`DefaultTimeoutAbortSec=10s`** (system and user; `G/usr/lib/systemd/system.conf.d/timeout.conf:3`) — completes fast shutdown; added.
8. **User-manager `DefaultTimeoutStopSec=10s`** (`C/usr/lib/systemd/user.conf.d/00-timeout.conf:2`) — prevents slow logout from hung user services; added.
9. **Coredump expiry `3d`** (`C/usr/lib/tmpfiles.d/coredump.conf:2`) — bounded crash-dump disk use; added.
10. **NVIDIA runtime PM on bind/unbind** (`C/usr/lib/udev/rules.d/71-nvidia.rules:2-9`, `P/garuda-hardware-profiles/90-nvidia-prime-powermanagement.rules:2-9`) — real battery savings on Optimus laptops; **not patched**, needs senior decision.
11. **Audio `power_save` AC/battery handling** (`C/usr/lib/udev/rules.d/20-audio-pm.rules:5-12`) — removes crackles on AC while preserving battery life; **not patched**, needs a helper script.
12. **`kernel.unprivileged_userns_clone=1`** (`C/usr/lib/sysctl.d/70-cachyos-settings.conf:31`, `G/usr/lib/sysctl.d/99-sysctl-garuda.conf:9`) — container/Flatpak compatibility; **not patched**, security decision.
13. **systemd-oomd slice defaults** (`C/usr/lib/systemd/system/system.slice.d/10-oomd-per-slice-defaults.conf:2-4`) — automatic recovery from memory pressure; **not patched**, conflicts with early swapping.
14. **irqbalance** (`P/performance-tweaks/performance-tweaks.install:7`) — better interrupt spread on multi-socket desktops; **not patched**, power cost on laptops/VMs.
15. **NVMe `kyber` instead of `none`** (`C/usr/lib/udev/rules.d/60-ioschedulers.rules:10-11` vs `S/sunshine-performance:52`) — CachyOS choice for fast queues; **not patched**, `none` is safer on unknown NVMe hardware.

## 3. Settings that could HURT, and the guard to use

The patch includes these guards where an added setting has a conditional risk:

- zram-size: only raise the pool on a desktop with RAM >= 8 GiB, no `/sys/class/power_supply/BAT*` device, and `! systemd-detect-virt --quiet --vm` (patch in `on()`); laptops/low-RAM/VMs keep `min(ram / 2, 8192)`.
- THP shrinker: only write the tmpfiles line when `/sys/kernel/mm/transparent_hugepage/khugepaged/max_ptes_none` exists, so pre-6.12 kernels are untouched.

Settings deliberately **not** added, with the guard a future patch would need:

| risky setting | who can be hurt | guard condition to put in the script |
|---|---|---|
| `zram-size = ram` unguarded (`C/usr/lib/systemd/zram-generator.conf:3`) | 4 GiB laptops and VMs: compression metadata/CPU cost | `mem_mb -ge 8192 && no_battery && ! systemd-detect-virt --quiet --vm` (implemented as a smaller cap instead of full `ram`). |
| SATA ALPM `max_performance` (`C/usr/lib/udev/rules.d/50-sata.rules:2-5`) | laptop battery life | only generate the rule if no `/sys/class/power_supply/BAT*` and `! systemd-detect-virt --quiet --vm`; also expose an AC/battery udev toggle like CachyOS audio does. |

| PCI latency `setpci` (`C/usr/bin/pci-latency:15-19`) | old chipsets, VirtualBox/VM virtual PCI | skip inside VMs (`systemd-detect-virt --quiet --vm`), apply only to class 0403 audio devices, and keep a documented revert path. |

## 4. What the CachyOS helpers do, and Sunshine's equivalent

All of these were read completely; line references are to `C/`.

- **`usr/bin/game-performance`** (`:1-24`): (1) choose `powerprofilesctl`, else `tlpctl`, else fail (`:3-10`); (2) if the tool has no `performance:` profile, `exec "$@"` unchanged (`:13-15`); (3) if `GAME_PERFORMANCE_SCREENSAVER_ON` is set, `exec <tool> launch -p performance -r ... -- "$@"` (`:18-20`); (4) otherwise wrap that in `systemd-inhibit --why ...` so the screensaver/suspend is held while the game runs (`:22-23`). **Sunshine already has the equivalent**: `S/sunshine-game-run:1-12` parses `--hud`, prepends `mangohud`, prepends `gamemoderun`, checks `powerprofilesctl list | grep -q 'performance:'` (`:9`) and uses `systemd-inhibit ... powerprofilesctl launch -p performance -r ... --` (`:10`), falling back to `exec "$@"` (`:12`). Recommendation: **ship no new script**; document `sunshine-game-run %command%` (already printed by `S/sunshine-gaming:67`). If the senior wants a CachyOS-named alias anyway, the exact new file should be `/usr/local/bin/sunshine-game-performance` (repo path `overlay/system/usr/local/bin/sunshine-game-performance`) containing the same four commands as `S/sunshine-game-run:4-12`: `--hud` parsing, `cmd=(mangohud "${cmd[@]}")`, `cmd=(gamemoderun "${cmd[@]}")`, and `exec systemd-inhibit --why "Sunshine OS game run" powerprofilesctl launch -p performance -r "Sunshine OS game run" -- "${cmd[@]}"`.
- **`usr/bin/kerver`** (`:1-65`): prints `/proc/version`+`uname -a`, x86_64 linker support, CPU config `CONFIG_*` flags from `/proc/config.gz`, current disk schedulers from `/sys/block/*/queue/scheduler`, and the enabled sched_ext BPF scheduler parsed from `journalctl -k` plus its process options (`:3-36,38-64`). It is a diagnostic, not a tuner; Sunshine's `bench` (`S/sunshine-performance:105-113`) covers boot time, RAM, services, schedulers and governor but not sched_ext — a future `sunshine-performance bench` line could add `journalctl -k | grep -i scheduler`.
- **`usr/bin/topmem`** (`:1-219`): a Lua/luv tool that scans `/proc`, sums RSS/Swap/KSM profit per executable name, sorts by rss/swap/ksm and prints the top N (`:24-46,67-116,135-150,168-219`). Sunshine's `bench` only prints total RAM/swap (`S/sunshine-performance:109`); adding `ps -eo rss,comm --sort=-rss | head` would be a cheap shell equivalent, but `topmem` itself needs `lua-luv`.
- **`usr/bin/pci-latency`** (`:1-19`): checks root (`:9-12`), sets all PCI devices to `latency_timer=20`, host bridge `0:0` to `0`, and audio class devices to `80` (`:15-19`); `pci-latency.service:6,9` runs it at boot if enabled. Risky on old hardware/VMs; not recommended (section 3).
- **`usr/lib/udev/audio-pm-ctl`** with `20-audio-pm.rules`: stashes `snd_hda_intel` `power_save` in `/run/udev/snd-hda-intel-powersave` (`:8-17`), sets `0` when AC is online (`:19-34,44-48`), restores the saved value or `10` on battery (`:36-42`), triggered on card init and power-supply add/change (`20-audio-pm.rules:5-12`). A full Sunshine port would need a new `/usr/local/lib/sunshine/audio-pm-ctl` plus a udev rule; this patch cannot ship that helper.
- **`usr/bin/zink-run`** (`:1-6`): exports `MESA_LOADER_DRIVER_OVERRIDE=zink`, `GALLIUM_DRIVER=zink`, GL/EGL vendor overrides and `exec "$@"`. Optional diagnostic for broken Vulkan drivers; not needed by default.
- **`usr/bin/dlss-swapper`** and **`dlss-swapper-dll`** (`:1-13`, `:1-12`): export `PROTON_ENABLE_NGX_UPDATER=1` and/or `DXVK_NVAPI_DRS_NGX_DLSS_*` overrides for latest DLSS presets, then `exec "$@"`. NVIDIA-only, opt-in; no Sunshine equivalent needed for baseline installs.
- **`usr/bin/eac-setup`** (`:1-569`) and **`eac-status`** (`:1-296`): set up and verify Easy Anti-Cheat Linux v2 (UEFI/TPM2/IOMMU checks `:129-144`, tools/keys `:148-157,245-303`, signed kernel/boot entry `:188-219,374-449,469-513`, boot once with `eac-setup boot` `:62-79`; status checks Secure Boot, TPM, db cert, signatures, cmdline, lockdown/BPF/module signatures, IOMMU and PCR7 `:50-262`). This is highly CachyOS-specific (signed kernel, own CA, boot managers); Sunshine should not copy it without its own signing infrastructure.
- **`usr/bin/sbctl-batch-sign`** (`:1-37`): refuses on Limine, requires root, walks `sbctl verify`, skips Microsoft/Windows files and CachyOS-signed EAC files, signs the rest with `sbctl sign -s`. Secure Boot maintenance, not performance.
- **`usr/bin/cachyos-bugreport.sh`** (`:1-181`) and **`paste-cachyos`** (`:1-15`): collect date/uname/cmdline, `inxi -Farz`, sched_ext, dmesg, current/previous journal and installed CachyOS repo packages (`:65-105`), redact hostname/user/SSID/IP/MAC/e-mail/UUID/file URLs (`:107-164`), ask before uploading via `paste-cachyos` (`:166-174`); the uploader POSTs a file to `https://paste.cachyos.org` (`:4,10`). Sunshine's `sunshine-diagnose` (not read here) is outside this task; no upload helper is proposed.
- **`usr/lib/systemd/system-generators/xswap-generator`** (`:18-22`) and **`cachyos-oomd-generator`** (`:19-34`): the former swaps zram for xswap when the new kernel interface exists; the latter generates per-slice oomd settings but refuses if `/proc/1/cgroup` is unreadable. Both are new-kernel features; not copied.
- **`usr/lib/iw-set-regdomain`** (`:25-92`): reads `/etc/iw-regdomain` or derives a country from the timezone and runs `iw reg set COUNTRY`; triggered by `85-iw-regulatory.rules:9` and the path unit `cachyos-iw-set-regdomain.path:8-9`. Regulatory, not performance; not copied.

No new script is created by this task; only the research document and the patch proposal are new files.
